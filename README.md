# 第二堂課 — Antigravity Vibe Coding 與 AI 輔助交易工具開發

> 本堂課資料將於上課前一天更新，請屆時重新下載。

---

## 📌 課程目標

本堂課的核心精神在於**「語意化開發 (Vibe Coding)」**。我們將帶領同學跳脫傳統從零學習 C# 語法的冗長過程，直接使用 **Antigravity** 作為開發介面，並以**群益期貨 CTA** 為終端執行環境。透過將官方 API 文件與基礎範例提供給 AI，我們能讓 AI 根據我們的「自然語言敘述」精準生成可編譯、可執行的交易指標與輔助工具！

---

## ⏳ 課程大綱 (共 3 小時)

### 第一小時：AI 協作環境與群益 CTA 破冰
- **開發環境介紹**：除了之前請同學安裝的 Antigravity 以外，也會介紹 VS Code, Cursor, KIRO 等業界常用 AI 工具的差異與應用場景。
- **Antigravity 基礎設定**：中文化、建立專屬交易專案資料夾。
- **群益 CTA 環境導覽**：熟悉群益 CTA 內的程式編譯器介面、如何匯入指標並將其掛載至技術線圖上。

### 第二小時：建立 AI 大腦與 Vibe Coding 實戰
- **建立專案上下文**：藉由讀取 `CTA-API` 與官方預設 `Examples`，將群益 CTA 的 C# 語法規則與框架「餵」給 Antigravity 學習。
- **Vibe Coding 實戰教學**：老師將隨機出題，現場示範與 AI 的協作開發過程（包含發問、AI 生成、匯入測試）。
- **完善 Debug 循環**：當遇到編譯錯誤或線圖顯示不如預期時，如何精準地將錯誤資訊或畫面狀態回饋給 AI 進行修正，掌握使用 AI 寫程式最重要的迭代手感。

### 第三小時：進階火力展示與期末專題預備
- **進階範本導讀與應用**：以 `AdaptiveTrendArrow.cs` 為核心範例，展示如何利用單純的指標架構結合趨勢訊號來在圖表上畫出買賣輔助箭頭。我們將以此為模板，學習讓 AI 替換買賣邏輯。
- **期末作業發佈 —「你的專屬 AI 輔助交易工具」**：在一個月後，請繳交一份透過 Antigravity 設計的個人指標或輔助策略，體驗從構思到自動化產出的開發里程碑。
