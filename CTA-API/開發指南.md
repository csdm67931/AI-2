## 1. 硬性規則（MUST / NEVER）— 違反會導致 Bug 或崩潰

以下規則來自實戰除錯經驗，**寫代碼時必須全部遵守**：

| # | 規則 | 原因 |
|---|------|------|
| R1 | `SimpleNumeric` **必須用四參數** `(min, max, decimalPlaces, step)`，如 `[SimpleNumeric(1D, 1000D, 0, 1)]` | 兩參數版本 `(min, max)` 的步進(step)是預設大值，使用者按一下微調鈕數值就跳到極值或負數 |
| R2 | `Lines["X"].Color` **必須在建構式(constructor)設定**；若要套用使用者面板參數，建構式設一次、`Init()` 再設一次 | 只在 `Init()` 設定顏色不一定生效 |
| R3 | `Update()` 和 `OnPaintChart()` 內部邏輯**必須全程 try/catch**（catch 留空即可） | 使用者切換商品/週期時平台會強制中止執行緒(Thread.Abort)，未捕捉的例外會彈出 `DisposeALL_Controls` 錯誤對話框 |
| R4 | 下單前**必須檢查報價 NaN**：`if (double.IsNaN(ask)) return;` | 開盤前/斷線時 `DayInfo.Ask/Bid` 回傳 `double.NaN` |
| R5 | `Update()` 開頭**必須檢查資料量**：`if (HistoryDataSeries.Count < Period) return;` | 資料不足時取值會出錯或算出錯誤值 |
| R6 | 訊號判斷**用索引 1（已收盤 K 棒）**；索引 0 是進行中 K 棒，每個 Tick 都會變動 | 用索引 0 判斷訊號會導致盤中反覆觸發、重複下單 |
| R7 | `Complete()` **必須清理資源**：集合 `.Clear()`、指標參照設 `null` | 降低執行緒中止期間的存取例外 |
| R8 | `SendAsync` 送單時，**state 必須在送單當下同步更新**，不能只在 callback 裡更新 | callback 是非同步延後執行，期間 `Update()` 可能再次觸發導致重複下單 |
| R9 | 參數必須宣告為 **public field**（欄位），不能用 property | 平台用反射讀取 field 生成參數面板 |
| R10 | 中文字型用 `"Microsoft JhengHei"`（微軟正黑體）；繪圖尺寸乘以 `gr.DpiX / 96f` 做 DPI 縮放 | 其他字型可能無中文字；高 DPI 螢幕不縮放會字太小 |
| R11 | `Credentials.ProjectName` 在建構式設定，是指標/策略在平台清單的顯示名稱，也是 `BuildIn.Custom()` 呼叫時的識別名 | 名稱錯誤會導致 Custom 呼叫失敗 |
| R12 | K 棒索引方向：**0 = 最新，數字越大越舊**（`GetValue(price, 5)` = 往前第 5 棒） | 方向弄反會取錯資料 |

## 2. 生命週期契約（Lifecycle Contract）

指標與策略共用相同生命週期。**方法簽名必須完全一致**（override）：

```csharp
public class MyScript : IndicatorBuilder   // 或 StrategyBuilder
{
    // [1] 建構式：平台載入時呼叫一次
    //     職責：設定 Credentials.ProjectName、Lines.Set() 註冊線、設顏色/線型、SeparateWindow
    public MyScript() : base() { }

    // [2] Init：使用者按「套用」後呼叫（此時參數面板的值已載入 field）
    //     職責：建立 BuiltInIndicator、設定 ScriptShortName、SetLineBegin、初始化狀態
    //     注意：使用者每次改參數都會重新呼叫 Init（先 Complete 再 Init）
    public override void Init() { }

    // [3] Update：每次報價(Tick)或新 K 棒時呼叫 —— 核心邏輯寫這裡
    //     args == TickStatus.IsQuote → 報價觸發
    //     args == TickStatus.IsBar   → 新 K 棒生成觸發
    //     歷史回補時會對每根歷史 K 棒依序呼叫一次
    public override void Update(TickStatus args) { }

    // [4] OnPaintChart：圖表重繪時呼叫（GDI+ 自訂繪圖，可省略不寫）
    public override void OnPaintChart(object sender, PaintChartEventArgs args) { }

    // [5] Complete：移除腳本/切換商品/改參數時呼叫
    //     職責：清理集合、參照設 null
    public override void Complete() { }
}
```

**執行順序**：`constructor → Init → Update×N（歷史K棒逐棒 → 之後即時Tick） → Complete`

## 5. 歷史資料 API（HistoryDataSeries）

`HistoryDataSeries` 是基底類別提供的屬性，代表當前圖表的 K 棒序列。

```csharp
int    HistoryDataSeries.Count;                            // K 棒總數
double HistoryDataSeries.GetValue(PriceType.Close);        // 索引 0（最新/進行中）的收盤價
double HistoryDataSeries.GetValue(PriceType.Close, i);     // 往前第 i 棒的收盤價
DateTime HistoryDataSeries.GetTimeUtc();                   // 索引 0 的時間（UTC）
DateTime HistoryDataSeries.GetTimeUtc(i);                  // 往前第 i 棒的時間（UTC）
```

**PriceType enum**：`Close` | `Open` | `High` | `Low` | `Typical`(=(H+L+C)/3) | `Medium`(=(H+L)/2) | `Weighted`(=(H+L+C+C)/4)

**索引語意表（極重要，見 R6/R12）**：

| 索引 | 意義 | 更新頻率 | 用途 |
|------|------|----------|------|
| `0` | 進行中 K 棒（未收盤） | 每個 Tick 變動 | 即時預覽、畫線跟盤 |
| `1` | 最新**已收盤** K 棒 | 只在收盤時定格 | **交易訊號判斷（標準做法）** |
| `n` | 往前第 n 棒 | 不變 | 歷史計算 |

## 7. 內建指標 API（IndicatorsManager.BuildIn）

在 `Init()` 中建立，回傳 `BuiltInIndicator` 物件。指標和策略都能用。

```csharp
private BuiltInIndicator ema, rsi, atr, custom;

public override void Init()
{
    // MA: (資料源, 週期, MAMode, 位移, 價格來源)
    ema = IndicatorsManager.BuildIn.MA(HistoryDataSeries, 20, MAMode.EMA, 0, PriceType.Close);
    // MAMode enum: SMA | EMA | SMMA | LWMA

    rsi = IndicatorsManager.BuildIn.RSI(HistoryDataSeries, 14);
    atr = IndicatorsManager.BuildIn.ATR(HistoryDataSeries, 14);

    // MA 也可用委派供價（自訂每棒的計算來源）：
    // double MyPriceFunc(int index) { return ...; }
    var maByFunc = IndicatorsManager.BuildIn.MA(MyPriceFunc, 10, MAMode.SMA);

    // 呼叫「自訂指標」：("ProjectName", 資料源, 依該指標參數面板順序傳入參數...)
    custom = IndicatorsManager.BuildIn.Custom("3MASignal", HistoryDataSeries, 5, 10, 25, 1);
}

public override void Update(TickStatus args)
{
    double v0 = ema.GetValue();        // 索引 0 的值
    double v1 = ema.GetValue(1);       // 索引 1 的值（已收盤，訊號判斷用）
    double x  = ema.Lines[0][1];       // 等價寫法: Lines[線序號][偏移]
    double y  = ema.Lines[0].GetValue(1);
    // 多線指標（如 MACD、Bands）用 Lines[0], Lines[1], Lines[2] 取不同線
}
```

**完整內建指標清單**（皆為 `IndicatorsManager.BuildIn.XXX(...)`，多數有多個重載）：

| 分類 | 方法名 |
|------|--------|
| 均線 | `MA`(SMA/EMA/SMMA/LWMA), `Alligator` |
| 震盪 | `RSI`, `Stochastic`, `CCI`, `WPR`, `DeMarker`, `Momentum`, `RVI` |
| 趨勢 | `ADX`, `MACD`, `OsMA`, `SAR`, `Ichimoku` |
| 波動 | `ATR`, `Bands`(布林通道), `Envelopes`, `StdDev` |
| 量能 | `AD`, `OBV`, `MFI`, `Force`, `BWMFI` |
| Bill Williams | `AC`, `AO`, `Fractals`, `Gator` |
| 自訂 | `Custom("ProjectName", dataSeries, params...)` |

### 8.1 環境物件

### 8.2 下單（OrdersManager）

```csharp
// OrderRequest 建構式簽名:
// OrderRequest(OrderType type, Instrument instrument, Account account,
//              OrderSide side, double quantity, double? price, double? stopPrice = null)

double ask = InstrumentsManager.Current.DayInfo.Ask;
if (double.IsNaN(ask)) return;                              // R4

var req = new OrderRequest(OrderType.Market,
                           InstrumentsManager.Current,
                           AccountManager.Current,
                           OrderSide.Buy, 1, ask);

// 可選屬性（送單前設定）:
req.StopLossPrice   = ask - 50;      // 掛單同時帶停損
req.TakeProfitPrice = ask + 100;     // 掛單同時帶停利
req.TIF             = TimeInForce.Day;
req.Comment         = "my note";
// 其他: StopPrice, StopLossLimitPrice, TrailingStopOffset, ExpirationTimeUtc, Leverage, ProductType

// 非同步送單（建議；R8: state 在送單當下就要更新）
OrdersManager.SendAsync(req, (TradeResult result) => { orderId = result.Id; });
state = State.Long;                  // ← 不能只在 callback 裡改

// 同步送單
TradeResult r = OrdersManager.Send(req);

// 查詢/刪改
List<Order> working = OrdersManager.GetOrders(true);                          // true = 僅工作中訂單
List<Order> buys    = OrdersManager.GetOrders(true, o => o.Side == OrderSide.Buy);
OrdersManager.Cancel(order);                       // 同步刪單；也有 CancelAsync(order, ok => {})
OrdersManager.Update(replaceOrderRequest);         // 改單；也有 UpdateAsync
```

**enum 值**：
- `OrderType`: `Market` | `Limit` | `Stop` | `StopLimit` | `TrailingStop` | `OCO` | `Manual`
- `OrderSide`: `Buy` | `Sell`
- `TimeInForce`: `Day` | `GTC` | `IOC` | `FOK` | `GTD` | `GTS`

### 8.3 部位管理（PositionsManager）

```csharp
List<Position> all  = PositionsManager.GetPositions();
List<Position> mine = PositionsManager.GetPositions(x => x.ID == orderId);   // Predicate 過濾

bool ok = PositionsManager.Close(position);                 // 全平；Close(pos, qty) 部分平倉
PositionsManager.CloseAsync(position, null, success => { });
PositionsManager.CloseAll(AccountManager.Current);          // 平掉帳戶所有部位

PositionsManager.SetStopLoss(position, price);              // 設/改停損
PositionsManager.SetTakeProfit(position, price);            // 設/改停利
PositionsManager.SetTrailingStop(position, offset, ticks);  // 移動停損
PositionsManager.RemoveStopLoss(position);
PositionsManager.RemoveTakeProfit(position);
// 以上皆有 XxxAsync(..., Action<bool> callback) 版本
```

**Position 屬性**：`ID`, `OpenOrderID`, `Instrument`, `Account`, `Side`(PositionSide), `Quantity`, `OpenPrice`, `OpenTimeUtc`, `NetPnL`, `GrossPnL`, `SLTPOrders`, `ProductType`

### 8.4 策略狀態機模式（標準寫法，防重複下單）

```csharp
private enum State { Flat = 0, Long = 1, Short = -1 }
private State state;        // Init 中設為 State.Flat
private string orderId;

// Update 中的標準流程:
// 1. 訊號翻轉時 → 先查 GetPositions(x => x.ID == orderId) 平掉舊倉
// 2. 再檢查 state 避免重複進場: if (state != State.Long) { 下單; state = State.Long; }
// 3. R8: state 在 SendAsync 呼叫的同一行後立即更新
```

## 9. 自訂繪圖 API（OnPaintChart）— 主要用於指標

```csharp
private int winNum;

public override void Init()
{
    // 取得自己所在的圖表視窗編號（副視窗指標需要正確的 winNum 才能座標轉換）
    winNum = ChartSource != null ? ChartSource.FindWindow(this) : 0;
}

public override void OnPaintChart(object sender, PaintChartEventArgs args)
{
    try                                                     // R3: 全程 try/catch
    {
        if (ChartSource == null || HistoryDataSeries == null) return;
        if (args == null || args.Graphics == null) return;

        Graphics gr = args.Graphics;
        gr.SetClip(args.Rectangle);                         // 限制繪圖範圍

        float scale = gr.DpiX / 96f;                        // R10: DPI 縮放係數

        // ── 座標轉換 ──
        // (時間,價格) → 螢幕座標:
        PointF pt = ChartSource.GetChartPoint(new TimeValue(timeUtc, price), winNum);
        // 螢幕座標 → (時間,價格):
        TimeValue tv = ChartSource.GetTimeValue(new PointF(x, y), winNum);
        // 可見範圍: 左邊界 GetTimeValue(new PointF(0,0)), 右邊界 GetTimeValue(new PointF(args.Rectangle.Width,0))

        // ── 畫文字（R10: 中文用 Microsoft JhengHei）──
        using (var font  = new Font("Microsoft JhengHei", 16 * scale, FontStyle.Bold))
        using (var brush = new SolidBrush(Color.Yellow))
        using (var bg    = new SolidBrush(Color.FromArgb(190, 25, 25, 25)))  // 半透明底
        {
            SizeF size = gr.MeasureString("文字", font);
            gr.FillRectangle(bg, x, y, size.Width, size.Height);
            gr.DrawString("文字", font, brush, x, y);
        }
        // 其他: gr.DrawLine, gr.FillEllipse, gr.DrawRectangle ... (標準 GDI+)
    }
    catch { }                                               // R3: 靜默吞掉切換商品時的暫態例外
}
```

其他繪圖輔助類（進階，位於 TradeApi.Indicators）：`BarStamps`（K 棒標記）、`Clouds`（雲帶填色）、`Markers`、`Thresholds`（水平門檻線）、`PrimitiveFigure`。

## 10. 完整範本 — 指標（可編譯，直接改造使用）

```csharp
using System;
using System.Drawing;
using Runtime.Script;
using Runtime.Script.Charts;
using TradeApi.History;
using TradeApi.Indicators;

namespace MyIndicators
{
    public class MyIndicator : IndicatorBuilder
    {
        // ── 參數（R1: SimpleNumeric 四參數；R9: public field）──
        [InputParameter(InputType.Numeric, "週期", 0)]
        [SimpleNumeric(1D, 1000D, 0, 1)]
        public int Period = 20;

        [InputParameter(InputType.Combobox, "價格來源", 1)]
        [ComboboxItem("Close", PriceType.Close)]
        [ComboboxItem("Open", PriceType.Open)]
        [ComboboxItem("High", PriceType.High)]
        [ComboboxItem("Low", PriceType.Low)]
        public PriceType SourcePrice = PriceType.Close;

        [InputParameter(InputType.Color, "線條顏色", 2)]
        public Color LineColor = Color.Red;

        private BuiltInIndicator ma;

        public MyIndicator() : base()
        {
            Credentials.ProjectName = "MyIndicator";   // R11: 清單顯示名 + Custom() 識別名
            Lines.Set("MAIN");
            Lines["MAIN"].Color = LineColor;           // R2: 顏色在建構式設
            Lines["MAIN"].Width = 2;
            SeparateWindow = false;                    // 疊在主圖
        }

        public override void Init()
        {
            ScriptShortName = $"MyInd({Period})";      // 圖表左上角短名稱
            Lines["MAIN"].Color = LineColor;           // R2: 再套用面板參數
            Lines["MAIN"].SetLineBegin(Period);
            ma = IndicatorsManager.BuildIn.MA(HistoryDataSeries, Period, MAMode.EMA, 0, SourcePrice);
        }

        public override void Update(TickStatus args)
        {
            try                                        // R3
            {
                if (HistoryDataSeries == null) return;
                if (HistoryDataSeries.Count < Period) return;   // R5
                Lines["MAIN"].SetValue(ma.GetValue());
            }
            catch { }
        }

        public override void Complete()
        {
            ma = null;                                 // R7
        }
    }
}
```

## 11. 完整範本 — 策略（可編譯，直接改造使用）

```csharp
using System;
using Runtime.Script;
using TradeApi.Indicators;
using TradeApi.Trading;

namespace MyStrategies
{
    public class MyStrategy : StrategyBuilder
    {
        [InputParameter(InputType.Numeric, "口數", 0)]
        [SimpleNumeric(1D, 100D, 0, 1)]
        public int Lots = 1;

        [InputParameter(InputType.Numeric, "RSI 週期", 1)]
        [SimpleNumeric(2D, 100D, 0, 1)]
        public int RsiPeriod = 14;

        private enum State { Flat = 0, Long = 1, Short = -1 }
        private State state;
        private string orderId;
        private BuiltInIndicator rsi;

        public MyStrategy() : base()
        {
            Credentials.ProjectName = "MyStrategy";
        }

        public override void Init()
        {
            state = State.Flat;
            orderId = null;
            rsi = IndicatorsManager.BuildIn.RSI(HistoryDataSeries, RsiPeriod);
        }

        public override void Update(TickStatus args)
        {
            try                                                    // R3
            {
                if (HistoryDataSeries.Count < RsiPeriod + 1) return;  // R5
                if (args != TickStatus.IsBar) return;              // 只在新 K 棒判斷（防盤中反覆觸發）

                double value = rsi.GetValue(1);                    // R6: 用已收盤棒判斷

                if (value < 30 && state != State.Long)
                {
                    CloseCurrent();
                    double ask = InstrumentsManager.Current.DayInfo.Ask;
                    if (double.IsNaN(ask)) return;                 // R4

                    var req = new OrderRequest(OrderType.Market, InstrumentsManager.Current,
                                               AccountManager.Current, OrderSide.Buy, Lots, ask);
                    OrdersManager.SendAsync(req, r => orderId = r.Id);
                    state = State.Long;                            // R8: 立即更新
                }
                else if (value > 70 && state != State.Short)
                {
                    CloseCurrent();
                    double bid = InstrumentsManager.Current.DayInfo.Bid;
                    if (double.IsNaN(bid)) return;                 // R4

                    var req = new OrderRequest(OrderType.Market, InstrumentsManager.Current,
                                               AccountManager.Current, OrderSide.Sell, Lots, bid);
                    OrdersManager.SendAsync(req, r => orderId = r.Id);
                    state = State.Short;                           // R8
                }
            }
            catch { }
        }

        private void CloseCurrent()
        {
            if (string.IsNullOrEmpty(orderId)) return;
            var positions = PositionsManager.GetPositions(x => x.ID == orderId);
            if (positions.Count == 1)
                PositionsManager.Close(positions[0]);
            orderId = null;
            state = State.Flat;
        }

        public override void Complete()
        {
            rsi = null;                                            // R7
        }
    }
}
```
